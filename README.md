# UVCE FLAM RND Assignment

## 1. Problem Statement

The objective of this assignment is to determine the unknown parameters of a given parametric curve using the provided X-Y coordinate data.

The parameters to be determined are:

* `theta` — angle in degrees
* `M` — parameter controlling the exponential term
* `X` — horizontal translation parameter

The program compares the coordinates generated by the parametric equations with the coordinates provided in `xy_data.csv`.

An optimization technique called **Differential Evolution** is used to find the parameter values that produce the minimum error.

---

## 2. Parametric Equations

The curve is defined using the following parametric equations.

### X-coordinate

```text
x(t) = t cos(theta)
       - exp(M|t|) sin(0.3t) sin(theta)
       + X
```

### Y-coordinate

```text
y(t) = 42
       + t sin(theta)
       + exp(M|t|) sin(0.3t) cos(theta)
```

Here:

* `t` is the curve parameter.
* `theta` is the angle in degrees.
* `M` is the exponential parameter.
* `X` is the horizontal offset.
* `exp()` represents the exponential function.
* `sin()` and `cos()` represent the trigonometric functions.

The angle `theta` is converted from degrees to radians before using NumPy trigonometric functions.

---

## 3. Parameter Ranges

The optimization is performed within the allowed ranges specified in the assignment.

```text
0 < theta < 50 degrees
-0.05 < M < 0.05
0 < X < 100
6 < t < 60
```

The bounds used in the Python program are:

```python
bounds = [
    (0.0001, 49.9999),
    (-0.049999, 0.049999),
    (0.0001, 99.9999)
]
```

These bounds prevent the optimization algorithm from selecting values outside the specified parameter ranges.


The program reads the data using the Pandas library:

```python
data = pd.read_csv("xy_data.csv")
```

```python
x_expected = data.iloc[:, 0].values
y_expected = data.iloc[:, 1].values
```

The corresponding values of `t` are generated using:

```python
t = np.linspace(6, 60, len(data))
```

## 5. Curve Calculation

A Python function named `curve()` is used to calculate the predicted X and Y coordinates.

The function first converts `theta` from degrees to radians:

```python
theta = np.radians(theta_deg)
```

It then calculates the exponential and sinusoidal terms:

```python
e = np.exp(M * np.abs(t))
s = np.sin(0.3 * t)
```

Finally, the X and Y coordinates are calculated using the given parametric equations.

The function returns:

```python
return x, y
```

---

## 6. Error Function

An objective function is created to measure how closely the calculated curve matches the given CSV data.

The predicted coordinates are calculated using the current values of `theta`, `M`, and `X`.

The absolute difference between the expected and predicted coordinates is then calculated:

```python
error = (
    np.abs(x_expected - x_pred)
    + np.abs(y_expected - y_pred)
)
```

The total L1 error is calculated using:

```python
return np.sum(error)
```

A smaller L1 error indicates a better match between the calculated curve and the provided data.

---

## 7. Optimization Method

The optimization is performed using **Differential Evolution** from SciPy.

The following function is used:

```python
differential_evolution()
```

It searches through the allowed parameter ranges and attempts to find the values of `theta`, `M`, and `X` that minimize the objective function.

The optimization is performed using:

```python
result = differential_evolution(
    objective,
    bounds,
    maxiter=500,
    popsize=20,
    tol=1e-8,
    polish=True,
    seed=42
)
```

The optimization result is stored in the variable `result`.
